# 把反馈变成可验证的回改

适用于用户已经看过本次成果、希望继续调整的请求。沿用当前领域、选定方向和可改范围；指定元素与改法的小修改直接完成，不重开本流程。

## 先判断意见落在哪一层

| 用户原话 | 可观察原因与证据 | 本轮最小验证片段 | 修改位置 | 是否影响已确认项 |
|---|---|---|---|---|

“不高级”“没感觉”等感受先分解成假设：可能是构图比例、内容优先级、素材身份/质感、字阶/间距或控件细节。先看当前画面，挑有证据且容易撤回的一项，说明观察与预期差异；不要一次同时换配色、字体、素材和布局，导致无法判断改了什么。

例如品牌色与标题位置已认可时，仍可检查素材主体尺度、图文分组和辅助信息对比；不能把“更高级”解释为自动换成深色、发光或另一套品牌。

意见表是执行依据，可放在回复或已有交接载体里，不单独制造报告，不为低风险局部改动再等待一次确认。用户只要诊断或要求先看改法时，止于诊断/方案。存在会实质改变整页结构的歧义时，先呈现最小片段或已有参考，解决该决定再扩展。

## 保留已认可的内容

只把用户明确认可、选择的内容记为确认；沉默不是认可。清单记录具体可核对的位置与表现，并区分用户确认、现状观察和Agent提案。当前用户明确改变旧决定时按新决定执行并指出影响；含糊意见不自动推翻品牌和结构。

改动落在现有变量或共享组件；改前保留未过期的基线，改后用同视口、数据和状态取证。局部问题可比较同一裁切，共享修改补看其他代表位置，整体图仍用于判断连带影响。没有画面或操作能力就明确未验证，不用文字描述冒充前后截图。

## 停止猜改，重新诊断

同一意见在已做过有证据的调整后仍反复出现、同一区域的要求相互矛盾、意见不断转移且整体评价不变，或明显指向另一种方向时，暂停无依据的细节循环。指出哪些观察说明当前假设不成立，列出仍锁定的内容，再建议用小片段比较新的结构或素材假设。

重新探索只改变获准部分，不自动制作全站或扩大候选数。用户坚持沿原方向继续时，在原范围内处理新证据，避免每轮重复劝改方向。反馈越来越具体、影响范围缩小时则继续局部收敛，不因机械次数上限中断有效工作。

交付用“意见 → 观察 → 改法/位置 → 同状态结果与剩余项”说明，足以逐项回退。未经用户认可的新改动仍标提案；实际操作回归与审美判断分别记录。
