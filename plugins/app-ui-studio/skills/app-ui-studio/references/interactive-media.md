# 交互媒体、真实演示与传播素材

media-runtime、product-demo、campaign按需使用。这里只适配方法，不附带视频引擎、录屏软件、账号或发布器；来源版本见 [oil-ecosystem.md](oil-ecosystem.md)。

## 媒体格式与播放控制分开

已有视频或序列帧先检查元数据和关键画面，从分析、预算与接入开始，不因使用媒体专项就重新生成。只有素材本身的结构、姿态、遮挡等需要改变时才考虑已授权生成；普通过渡继续用项目代码，见 [motion-scroll.md](motion-scroll.md)。

分别确定输入来源、连续/分步/事件语义、随动/分段/自主播放、线性/环形/离散参数空间，以及背景属于页面还是媒体。滚动页面不自动意味着必须逐帧播放；透明需求也不能推导播放控制器。

根据随机访问、目标显示尺寸、DPR、解码/内存与传输预算选择视频、透明视频或帧资源；先做一段真实Pilot，测试后再量产。关键帧保持主体身份与场景关系，连续片段核对实际解码接缝；最终时间轴和帧率来自真实导出，不手工编造。

运行时明确拖动与滚动的仲裁、反向/重定位、循环边界、取消和预加载。冷缓存、快速换向、手机、资源失败与低动效分别验收；静态替代保留同等信息。离屏或隐藏停止资源工作，不默认预解码全部高分辨率帧，也不宣称未测的帧率或实时物理能力。

## 真实录屏与产品演示

先写实际用户路径、起始状态、目标环境、测试数据与需要遮蔽的信息，优先复用可用录屏工具，不自动安装原生App或浏览器扩展。真实屏幕、概念演示与模拟数据分别标注，录制权限不扩大为上传或发布权限。

保留源录屏与编辑版本，剪辑只去停顿、误讲或无关段落，不伪造成功步骤。字幕、鼠标强调、章节与画面时间轴对应；声音克隆、外部上传和收费服务需要各自授权。导出后实际回看画面、音轨、字形、清晰度与节奏，不以导出进程结束当成演示验收。

先分清原生录屏工程、现成视频和字幕文件，选择对应工具；不把修改工程当作已导出视频或已烧录字幕。在副本上编辑，计划绑定源文件身份、上下文版本和source时间轴，源改变就使旧计划失效并重新核对。按原音频、完整替代话术和屏幕活动判断语义，不能只看静音阈值批量删句；最终复听跳切与接缝。

字幕保留原始ASR、术语校对、人工修改与最终文件的对应关系。技术词优先用可读画面和音频验证后最小替换，语义猜测留待确认；人工润色、标点和删句不自动写入术语词库。只要翻译SRT时保持既有时间轴，不启动配音、章节、预览或烧录。现有成片、底图或字幕未变时从当前阶段续接，不重做上游制作。

产物沿用普通文件和明确身份关联，任务状态与内容分开保存；让使用者可从已完成阶段继续。工具入口仅按当前能力发现：screen-studio-editor处理原生工程，video-editor处理现成媒体，oil-subtitle/qwen_subtitle处理转录与翻译；它们不是本包依赖或安装指令。

## 封面、文章和平台草稿

从真实视频与核对过的字幕提炼标题和画面，不虚构工具能力或收益。不同画幅分别检查主体、文字安全区和裁切，规格按目标渠道当时要求核对；默认不添加创作者头像或套用上游人物素材。来源未变且产物已验收时复用，只重做受影响版本。

用户只要封面或演示时交本地产物。另有明确草稿请求时，按平台隔离账号、素材身份和恢复状态，检查真实上传完成及预览；部分失败不把全部状态写成成功。最终发布需要本次内容与目的地的明确授权，准备素材、长期配置、上传或READY均不等于已发布或发布授权。
