# 版本冻结、同状态对比与技能迭代

适用于同一项目的版本比较、已有表面精修和技能升级；不因普通调用强制建立比较实验。

## 先冻结事实

记录本轮实际读取的插件版本、清单和入口哈希。保存任务需要的最少版本副本或使用已有归档；不要只保存一个会被自动清理的缓存路径。版本标记与实际清单一致，后续缓存更新不改变本轮归属。

原有业务、品牌、数据fixture与关键状态分别锁定。候选在独立目录产生；不覆盖基线、失败截图、UNKNOWN、原始工具回执或其他智能体工作。若对照故意改变tone、布局或素材，将它列为变量，不能把差异直接当成版本质量的因果证据。

## 制作与观察

先复用合格素材，再按需要生成。生成方向图、可编辑源码、实际渲染截图和设备验收分别留证。方向稿可放比较页面作参考，不能替代真实组件截图。每条provider链说明哪些是本轮生成、哪些复用，图像完成不等于已接入或已验证页面。

使用同一产品、状态、日期/数据fixture、语言和视口捕获对应屏幕。验证干净首次加载、路由导航、重要交互与减少动态效果。保留键盘焦点样式；如果截图出现非目标状态，回到真实目标状态重拍，不通过隐藏异常制造结果。

## 可比性命令

```bash
python3 "<skill-base>/scripts/studio.py" compare baseline/capture.json candidate/capture.json --output comparison.json
```

无 `--output` 时只输出JSON、不写文件；提供时仅排他创建一个新报告，父目录须已存在，已有目标拒绝覆盖。退出0表示文件契约有效且可比，1表示契约有效但条件不可比，2表示输入或输出无效。报告始终 `visual_quality_verified=false`；它不打视觉分、不证明图像来源、截图内容、提供方执行或真实设备表现。

每份manifest的引用相对其父目录，使用该目录内的文件：

```json
{
  "schema_version": 1,
  "product": "qike",
  "plugin_version": "1.2.0",
  "plugin_manifest": "provenance/plugin.json",
  "capture_context": {
    "locale": "zh-CN",
    "fixture": "qike-seed-v1",
    "state": "clean-initial"
  },
  "business_files": ["app.js"],
  "brand_assets": ["assets/sprout.png"],
  "screens": [
    {"id": "today", "artifact": "screenshots/today.jpg", "viewport": {"width": 390, "height": 844}}
  ]
}
```

plugin_manifest的version必须匹配plugin_version。不同插件版本允许比较；产品、capture_context、业务与品牌相对键及实际SHA-256、屏幕id集合与视口必须相同才可比。截图文件名与字节可以不同，逐屏报告changed。屏幕顺序不影响比较。

引用不得为绝对路径、含`..`或逃逸目录的符号链接，文件必须实际存在且非空。PNG/JPEG从实际头部读取宽高并核对声明，不按扩展名猜尺寸。头部校验不等于完整像素解码或图像真实性认证。无效JSON、重复键与非有限数不能进入有效清单。

## 审查与发布

把可比性、实际操作结果、客观几何/可读性和主观视觉判断分别报告。无差异、无改善证据或实验限制都应保留，不为了晋升技能降低标准。Harness²的一轮结果只能说明该任务上的观察，不能证明普适增益。

公开项目时，保留原始证据的本地副本；公开只用脱敏副本，移除账户、凭据、签名媒体链接、私有回执与本机绝对路径。原文图片及上游技能不因引用而可重新授权；只打包有权发布的代码、文档与素材。发布授权沿用当前用户要求，不把本地检查当公开发布回执。
