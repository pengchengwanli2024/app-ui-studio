# 产品前端、平台与业务理解

frontend、native-ios、node-editor、product-analysis只读取当前问题相关段落，不重跑全套设计。来源目录见 [oil-ecosystem.md](oil-ecosystem.md)。

## 状态必须属于正确的查询与动作

追踪请求对应的查询快照、分页、排序、对象ID和作用域。快速改筛选时，取消或忽略旧结果，不能让较晚返回的旧请求覆盖当前视图；选择状态要知道属于当前页、已加载集合还是全量匹配，不根据按钮文案猜测批量范围。

区分首次加载、保留旧内容刷新、真正为空、筛选无结果、请求失败和正在处理。失败保留输入、对象和位置；局部结果只更新对应范围，读回确认实际写入。复杂度来自当前业务时才增加状态机、缓存或队列，不为一次故障再做一套配置框架。

定位数据来源、父布局、共享组件与调用方式的责任，修真正出错的位置；共享修改核对使用处。运行当前风险所需检查并合并取证，不把每次局部修改变成全仓审计。只审查时不修代码。

主题改变把语义色、UI/代码字体和字号作为相关配置验证；持久化需版本与恢复策略，不能只保存一组随机颜色。需要固定上下文时，依据实际滚动容器和越界位置控制单一浮层，允许回到原文；保持原内容、焦点和滚动关系，清理重复监听。两项仅在产品确有对应需求时使用，不因此修改宿主外观或会话。

选择使用稳定对象ID和有序对象集合，范围选择记录锚点，数据变化时只清理失效ID；不能用行号或当前显示顺序重绑已有操作。右键、单项和批量操作先确定实际目标集合，再执行，不把“推荐了哪个方案”混同“正在查看/批注哪个对象”。

本地状态区分领域数据、当前选择、编辑草稿与主题偏好。恢复前验证schema版本、对象归属和内容指纹；相同文件名不能证明相同版本，过期草稿不能无声附到新内容。存储失败仍保留当前编辑，并提供可导出/手动复制的恢复路径；未写入成功不提示已保存。主题区分跟随系统与显式浅/深选择，系统变化仅影响跟随状态。

## iOS使用真实平台依据

核对实际技术栈、系统范围和现有原生组件；从当前Apple官方HIG读取当前功能需要的组件、导航和行为条目，保留来源与日期。上游的同步工具是可选来源工具，不自动写入已安装Skill；不能把不存在的来源快照说成已读。

平台单位、动态字体、返回语义、键盘、安全区、触控与读屏在对应模拟器或设备验收。Web原型可以交付布局和交互说明，但与真实原生实现分别记录，不凭截图宽度或静态样式认定原生通过。

## 节点编辑器先保契约，再测瓶颈

只有产品实际使用React Flow时进入本段。核对安装版本及当前官方API，保留节点/边/handle稳定标识、坐标、连接校验、选择、撤销、持久化和视口恢复。普通流程图不因此安装节点引擎。

先测真实图规模和目标设备下的拖动/缩放，再查过宽订阅、重复渲染、昂贵节点或布局重算；依据观察选择局部缓存、裁剪或层级细节。测试连线、框选、编辑输入、平移缩放冲突、撤销及保存；性能结论给测量条件，不编造提升百分比。

## 产品分析沿着用户走

仅分析任务先只读路由/入口、模型/Schema、核心业务状态与外部集成，沿调用关系补足关键分支；达到能说明主要旅程与异常时停止，不扫描无关个人目录或机械读完整仓库。

按用户进入、识别、判断、行动、看到结果与失败恢复组织说明。PRD表示预期，源码与运行表示现状，推断和Unknown另标。实体关系记录来源、标识、基数、可选性、生命周期与推断依据；影响链解释谁的行为或数据会改变。

用户只要分析就交分析，不修改业务、执行真实提交或自行生成多套报告。需要图时用适合的旅程/ER表达，格式服务于判断；没有运行环境不把代码阅读当端到端验收。
