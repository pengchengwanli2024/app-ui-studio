# 动效编排与滚动叙事

仅在本次请求涉及反馈、过渡、操控或叙事时读取。复用现有技术栈与节奏，不因加载专项强制增加入场、弹簧、平滑滚动或新依赖。

## 动作、业务状态与时间分开

先列实际触发点、受影响对象、起止状态、打断方式和低动效表现。每段动态服务于反馈、连续性、引导或已选品牌表达；无法说明作用的先省略。

| 时机 | 可立即呈现 | 必须等待什么 |
|---|---|---|
| 按下/选择/展开 | 按压、焦点、局部展开与清楚的处理中反馈 | 不等动画结束才发请求或更新本地选中 |
| 慢请求 | 稳定的等待状态、已知进度与可用取消入口 | 不伪造进度、完成勾号或完成庆祝 |
| 真实回执 | 已确认结果及受影响对象的局部变化 | 保存类结果按契约刷新/读回；超时未知按回执查询恢复 |
| 离开/返回 | 保留上下文、从当前位置衔接 | 不把未完成请求自动视为失败或重新提交 |

起点靠近触发对象，关联变化沿一条可理解的方向衔接；高频任务用短促且稳定的反馈。先沿用项目时长/缓动变量，未建立节奏时再提出少量角色值并实际调试，不把某组弹簧参数当跨库规范。

连续或反向输入时，从当前可见位置继续，避免跳回起点或留下旧快照。共享元素名称需唯一且真是同一对象；失败时直接显示正确终态。菜单和对话框的焦点、键盘、滚动锁不能等待装饰动画，关闭后返回合理位置。不要在 SVG 已有定位上叠加会覆盖它的 transform；优先把位移与表现放在不同容器。

尽量动画变换与透明度，明确属性而非 transition: all。逐帧任务要有停止与清理：离屏、页面隐藏、卸载和无待办时暂停，移除监听、观察器与库实例。无法测量时不宣称帧率或性能提升。

减少动态效果时，状态与信息直接到位，保留必要的处理中提示和结果语义。完整路径不依赖动画结束、声音、悬停或自动播放。

## 滚动叙事先有静态内容，再绑定进度

适用于品牌、宣传、发布或展览中的过程表达。后台、表单、内容阅读与长文档沿用原生滚动和稳定布局；不为这些页面默认引入固定舞台或全局平滑滚动。两种表面同时交付时，只在获准的说服页使用叙事。

先写分镜：`段落/主角 → 起止画面 → 进度区间 → 文字何时稳定可读 → 手机替代 → 减少动态效果替代`。主角来自产品本身的对象或过程；不要靠通用粒子和光球替代无法解释的业务。

区分两种机制：

- **滚动驱动**：画面是滚动位置的函数，停止即停止，反向自然回退；刷新、锚点跳入或恢复到中段时立即显示对应画面。
- **滚动触发**：进入阈值后播放一次有时长的出场；内容阅读中不反复消失或在阈值附近重播。

产品装配可由部件分离、对齐、装入、整体展示组成，精确关系由代码或经过核对的序列素材表达。固定区间的长度与解除位置按内容和设备决定；正文、CTA和输入保持可读可点，给长演示清楚的跳过路径，不接管用户滚轮或强迫逐屏翻页。

先复用项目成熟的动效/滚动实现；简单触发可用平台能力，复杂进度与固定舞台再选合适库，不为一次演示自建框架。依赖版本、用法和许可按实施时的官方资料核对；离线交付确保资源本地可用。图片/视频按设备预算加载，不默认解码全部大帧；预渲染效果不能宣称具有实时物理能力。

手机空间不足时，可缩短或取消固定区间，改为顺序图文；减少动态效果、脚本/媒体失败时也用可完整阅读的静态步骤。替代方案保留同等信息，不要求所有设备保留相同演出。

## 真实检查

正常速度操作、反向和快速连续输入；检查中断、旧状态残影、焦点和保存读回。叙事从头到底再返回，跳到中段刷新、改变视口、测试锚点和减少动态效果；确认固定结束后没有空洞、遮挡或跳跃。静帧不能证明这些时间行为，模拟网络与设备也应标明范围。
