# 明确要求的多方向对比

仅在用户要求比较视觉方向、改动幅度或版式时应用；默认仍深化一个推荐方向。沿用原任务的领域、品牌、功能与授权范围，不把比较升级为重塑。

先说明比较什么。新方向可以比较构图、类型语言与视觉重心；已定品牌内的版式比较锁定配色、字体与素材，只变页面骨架、比例和阅读顺序；存量改动档位比较修改范围与迁移代价。用户给数量就按数量，没给时可从三个有明确差别的候选开始。

## 候选共用输入，各自回答一个假设

| 候选 | 核心假设与结构差异 | 共用锁定项 | 主要收益 | 代价/风险 |
|---|---|---|---|---|

任务、文案事实、示例数据、CTA和素材质量保持可比，避免用高质量新图对低质量占位图，把素材差误判为版式差。不把同一模板换色称作不同方向，也不为差异改变已确认的操作习惯。

先做足以决定的首屏或关键片段，选中前不写完整站点和全部交互。使用相同视口、数据与状态，标清概念图、静态原型或实际渲染；不能根据它们推断未实施的业务能力。看整体节奏与原尺寸细节，按当前任务比较识别效率、主操作、可读性、窄屏裁切与实现代价，给出推荐和依据。

用户需选择且未授权代选时，交候选后停止等待；已说“你定/直接做”则自主选择并说明，再只深化所选方案。拼合候选先写清保留与冲突点；会推翻锁定结构时先解决该决定，不同时铺开多套系统。

## 本地截图对比页

`python3 "<技能目录>/scripts/studio.py" board manifest.json --output <不存在的新目录>` 把本地 PNG/JPEG 截图复制为一个便携对比页；支持视口切换、原尺寸预览、候选选择与意见复制。它不生成设计、不调用模型、不评分；用户的选择不自动修改项目。清单格式见 [comparison.md](comparison.md) 的截图对比页一节。

对比页用于共同观察；`studio.py compare` 继续检查冻结版本证据的可比性，两者都不能认证视觉质量。只读评审可以查看既有候选，但不因加载本专项创建、修改或重设计它们。
