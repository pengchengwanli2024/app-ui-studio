# Contributing

Keep instructions and checks aligned with real host capabilities. Preserve existing product behavior, brand inputs, and failed evidence when adding a design mode.

Run the project checks described in the README, and attach final rendered screenshots when changing examples. Label generated direction images separately from actual UI captures. Do not claim native-device, screen-reader, provider execution, or editor-layer acceptance from static files alone.

Keep new tests focused on observable contracts. Never replace evidence with synthetic passing receipts. Do not commit credentials, signed media URLs, local account identifiers, private tool logs, or absolute home-directory paths. Optional upstream skills remain external dependencies.
