## 可观察差异

| 产物 | 1.1.0 冻结基线 | 1.2.0 实测候选 |
| --- | --- | --- |
| 今天 | 平静纸本，单色主要按钮 | 同一小芽与任务，受控光感、选择反馈和边缘精修 |
| 专注准备态 | 25:00，原有计时组件 | 相同任务/计时行为，数字字阶与材质精修 |
| 记录 | 185 分钟示例统计与七日图 | 同一数据、结构和过滤行为，柱图与层级微调 |
| 宣传页 | 原有抽象背景与独立品牌图 | Lovart 新主视觉，左侧真实手机界面，桌面/手机分别核对裁切 |
| image 方向稿 | 原有三屏图 | 本轮新生成三屏方向图，明确标为概念参考 |

原版 12 个源/素材文件逐一匹配冻结 SHA-256；`app.js`、`assets/sprout.png` 跨版本字节相同。两份 capture 清单采用相同产品、日期、语言、初始 fixture、light/reduced-motion 与对应视口：APP 三屏 390×844、桌面宣传页 1440×1000、手机宣传页 390×844。两个插件版本号来自独立的最小脱敏清单快照，完整原包留在本地。

tone 是刻意变化的变量。这组结果支持“新增能力能在已有品牌中落地”，不支持“1.2 在所有产品上更美”或“新版本单独造成质量提升”。个人专注 APP 没有被改造成订阅 SaaS；仅复用适用的已有项目/表面/tone 配置。

## 实际验证

| 范围 | 方法与结果 |
| --- | --- |
| 响应布局 | APP 三路由 × 320/390/430 宽，宣传页 320/390/430/1280/1440 宽，共 14 组；无横向溢出、坏图、重复可见 H1；有效控件至少 44 CSS px |
| 干净初始路由 | 三屏首次加载 headerTop=0、scrollY=0；1440×1050 三 iframe 展示同样通过 |
| 任务 | 空白任务不新增；新增后刷新保留；完成与取消完成通过。屏下表单先真实滚动再点击 |
| 计时 | 15:00 正常开始并自然下降；暂停后等待保持；刷新仍暂停；继续与取消结束通过 |
| 记录 | 手动结束产生“专注不到 1 分钟 · 本机”；刷新记录仍在；仅本机过滤排除七条示例。未声称过滤开关刷新后保持 |
| 宣传页/对照 | 看看界面滚至目标（目标距顶部 32px）；体验 CTA 打开 APP；五个对照按钮切换对应的两张真实图片 |
| 键盘/动态 | 实际 Tab 焦点为 3px 实线，light + reduced-motion 下检查；保留有效焦点样式 |
| 静态审查 | Impeccable 返回 exit 2，3 个 warning 原样保留并逐项审查；没有通过关闭规则制造零警告，见 [记录](../evidence/v1.2.0/impeccable.json) |
| 颜色 | 新主按钮渐变较亮端 #2C5D47 对 #F7F6EF 为 7.0133:1；这是颜色对检查，不代替全站可访问性认证 |
| 发布源码 | Python 3.11、3.13、3.14 分别通过 42 项 CLI 契约；预检 14 项通过；JavaScript 语法与插件包 CRC/结构检查通过 |

Chrome DevTools 在最后一条记录操作阶段反复重置，Playwright MCP 又因 socket 路径过长不能初始化。保留中断事实后，使用独立短路径 Playwright CLI 会话完成补验；没有修改应用内部状态、加速时钟或拿旧截图替代。本地旧失败图片仍保留，公开有脱敏副本。

## 媒体与技能边界

image 本轮新生成 1672×941 三屏方向图；Lovart 本轮新生成 2048×1152 主视觉，生成后实际查看并接入宣传页。旧小芽资产复用。提供方完整回执在本地私有证据目录；公开仅包含提示词、结果、哈希、尺寸和用途，不包含连接/项目/任务 ID 或签名 URL。

四项上游技能仅列依赖与来源，不复制入仓库。UI/UX Pro Max、Mobile App Design 和 Impeccable 按适用职责使用；Taste 当前安装版本明确不覆盖多步骤产品 UI，因此未虚称它执行了这一范围的检查，仍保留其外部依赖。

未验证原生真机、系统键盘遮挡、完整读屏、完整 15/25/45 分钟自然结束、Figma 可编辑图层或完整图片像素解码。示例统计不是用户真实数据。
